Panduan Pembaruan Aplikasi

Sistem ini dirancang sangat fleksibel (Modular). Jika di kemudian hari Anda ingin menambahkan modul baru (contoh: Data Keuangan atau Perpustakaan), ikuti 3 langkah berikut:

1. Buat Database Baru (Google Sheets)

Buat sheet/tab baru di file Google Sheets Anda (misal: "Keuangan"). Isi Baris 1 dengan judul kolom yang Anda butuhkan. Aplikasi ini merender kolom form dan tabel secara otomatis dari baris 1 tersebut.

2. Tambahkan Navigasi di Frontend (HTML)

Buka kode HTML ini, cari bagian <nav> di Sidebar. Tambahkan tombol (button) baru dengan fungsi onClick navigate('keuangan').

3. Daftarkan Modul di Konfigurasi JS

Cari variabel appConfig di dalam kode JavaScript. Tambahkan objek baru ke dalamnya, contoh:

keuangan: {
    title: 'Data Keuangan',
    subtitle: 'Manajemen SPP dan Kas Madrasah',
    headers: ['ID_Transaksi', 'NIS', 'Nama', 'Nominal', 'Tanggal'],
    data: [] // Kosongkan, data akan diisi dari Backend
}

Cukup itu saja! Tabel, Form Tambah Data, dan fitur Import/Export Excel akan otomatis beroperasi untuk modul baru tersebut karena menggunakan rendering dinamis.
